### MyntraDemo - Java MVC E-Commerce Web Application (Mar 2026 - May 2026)

> Live Demo: [myntrademo-v2.onrender.com](https://myntrademo-v2.onrender.com)

A full-featured Myntra-style e-commerce web application built from scratch at Tap Academy using Java MVC architecture.

| Feature | Details |
|---------|---------|
| Authentication | Session-based user login and registration |
| Shopping Modules | Product listing, Product details, Cart, Checkout, Order management |
| Database Flows | Products, Cart, Orders - all database-driven using JDBC |
| Architecture | Clean MVC - Servlets (Controller), JSP (View), JDBC+MySQL (Model) |
| Navigation | User-friendly shopping flow with smooth navigation |
